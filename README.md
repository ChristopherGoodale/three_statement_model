# Three-Statement Financial Model

Linked income statement, balance sheet, and cash flow statement for a real public company, driven by assumptions (revenue growth, margins, working capital, capex/D&A). See [finance_skills_projects.md](../finance_skills_projects.md) (project #1).

## Structure

- `data/` — source financials (historical filings/statements pulled for the company being modeled)
- `three_statement_model_guide/` — companion learning guide documenting design decisions as the model is built

## Workflow

Historical data is gathered here as an Excel file, then the model itself is built manually in Google Sheets for presentation. This repo tracks the source data and notes, not the live model.
