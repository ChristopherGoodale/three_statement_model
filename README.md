# Three-Statement Financial Model — SiteOne Landscape Supply (SITE)

Linked income statement, balance sheet, and cash flow statement for SiteOne Landscape Supply, Inc. (NYSE: SITE, CIK 0001650729), driven by assumptions (revenue growth, margins, working capital, capex/D&A). See [finance_skills_projects.md](../finance_skills_projects.md) (project #1).

## Structure

- `data/` — historical financials sourced from SEC EDGAR XBRL R-files (FY2023–FY2025 10-Ks): `SiteOne_10K_FY2023-2025_FIXED.xlsx`, with Income Statement / Balance Sheet / Cash Flow Statement tabs and built-in tie-out checks
- `three_statement_model_guide/` — companion learning guide documenting design decisions as the model is built

## Workflow

Historical data is gathered here as an Excel file, then the model itself is built manually in Google Sheets for presentation. This repo tracks the source data and notes, not the live model.
